# Secretary

Локальная голосовая ассистентка для Android (Galaxy S25), которая работает без интернета.

- Голосовой диалог на русском: распознавание, языковая модель и синтез речи прямо на телефоне.
- Рабочий режим: ответы по документации лифтов, заметки, задачи, проекты.
- Долговременная память и характер с эмоциями.
- Облачный шлюз к Claude API — только когда есть сеть и только для рабочих задач.
- Без подписок: все модели и библиотеки бесплатные и хранятся локально.

Подробная архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Структура

| Папка | Что внутри |
| --- | --- |
| `docs/` | Архитектура и архитектурные решения (`adr/`) |
| `prototype/` | Прототип на Python для Mac |
| `android/` | Приложение на Kotlin |
| `native/` | llama.cpp, whisper.cpp и JNI-обёртки |
| `unity/` | Проект аватара |
| `persona/` | Карточки персонажа и промпты (YAML) |
| `tools/ingest/` | Сборка пакетов документации |
| `evals/` | Эталонные диалоги для проверки качества |
| `models.yaml` | Список моделей со ссылками (сами модели в репозиторий не кладутся) |

## Статус

Этап 1 — подготовка. Следующий — голосовой прототип на Mac.
