# Как устроена «живость» Миры

Ориентиры — открытые проекты компаньонов и исследования:

| Идея | Откуда | Как у нас |
| --- | --- | --- |
| Поток памяти + «рефлексия» (агент сам осмысляет прожитое) | Generative Agents (Park et al., 2023) | При сжатии разговора Мира пишет `mira_note` — что она почувствовала/подумала; хранится в эпизоде |
| Блоки «ядра» памяти, которые всегда в контексте | Letta / MemGPT | `context_block`: эпизоды, факты, задачи |
| Карточка персонажа: описание, примеры реплик, сценарии | формат character cards (SillyTavern и др.) | `persona/mira.yaml`: biography, speech, behaviour, examples |
| Эмоции влияют на голос и аватар, VRM-персонаж, голосовой диалог | Amica, AIRI (moeru-ai), Open-LLM-VTuber | Настроение дня + сиюминутные эмоции → промпт, позже → мимика и интонация |
| Своя жизнь и «новости» | — | `day_events`: одна новость в день, без повторов два дня подряд |

Принципы:
1. Характер задаётся данными (`mira.yaml`), код только собирает их в промпт.
2. Реакции — сценарии «если → то» (`behaviour`), а не жёсткие правила.
3. Она может не соглашаться, ошибаться в бытовом, признавать незнание — но не выдумывает факты.
4. Один вопрос за реплику; помнит и сама возвращается к прошлым темам.

Дальше: реальные новости через облачный шлюз (дайджест по интересам Андрея, когда есть сеть), сиюминутные эмоции как отдельная оценка после каждого ответа → интонация Silero и мимика аватара.
