# ADR 0001: Offline-first и без подписок

Дата: 2026-10-17 · Статус: принято

## Решение

Все основные функции работают на телефоне без сети. Модели, голоса и библиотеки — только бесплатные, с открытыми лицензиями. Допустимы разовые покупки (3D-модель, анимации). Единственная плата по факту — Claude API для облачного шлюза.

## Почему

Связь на объектах бывает не всегда. Владелец проекта не хочет зависеть от подписок и сторонних сервисов.

## Следствия

- Качество ограничено моделями на 3–4B параметров.
- Своего сервера нет: телефон обращается к Claude API напрямую.
