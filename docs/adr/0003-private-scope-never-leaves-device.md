# ADR 0003: Приватные данные не покидают телефон

Дата: 2026-10-17 · Статус: принято

## Решение

Каждая запись в памяти помечена областью `work` или `private`. Облачный шлюз жёстко отфильтровывает всё с областью `private`. В рабочем режиме приватные записи не попадают в поиск по памяти.

## Почему

Приватный режим должен оставаться полностью локальным. Кроме того, Claude API не обрабатывает откровенный контент.
