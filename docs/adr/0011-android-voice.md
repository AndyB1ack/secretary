# 0011. Голос Миры на телефоне — свой нейроголос (sherpa-onnx + Piper)

Дата: 2026-10-17. Статус: принято.

## Контекст
Системные голоса Android (Samsung TTS, Google, Vocalizer) Андрей прослушал — «металлические», не годятся.
Silero (голос на Маке) на Android без Python не запустить: модели в формате torch.package с питоновской обработкой текста.

## Решение
- Движок: sherpa-onnx (готовый AAR, офлайн, ONNX Runtime).
- Голос: Piper VITS `ru_RU-irina-medium` (единственный женский русский Piper). Синтез ~0,1× реального времени на CPU.
- Модель лежит в `files/voice/` на телефоне, кладётся скриптом сборки; без неё — системный TTS как запасной.
- Голос за интерфейсом (`MiraVoice`): заменить на другой (дообученный Piper, Silero ONNX, клон с согласия) — без переделки приложения.

## Последствия
- APK больше примерно на 25 МБ (только arm64), голос ~65 МБ на телефоне.
- Голоса на Маке (Silero xenia) и телефоне пока разные.
