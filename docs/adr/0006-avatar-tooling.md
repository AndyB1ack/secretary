# ADR 0006: Инструмент и стиль аватара

Дата: 2026-10-17 · Статус: инструмент выбран, стиль открыт

## Решение

- VRoid Studio не подходит: аниме-стиль и упрощённое тело.
- Основной инструмент — **Character Creator 4** (разовая покупка, экспорт в Unity). Бесплатные альтернативы для проб — MakeHuman и Daz Studio.
- Одежда — отдельные слои, снимаются и надеваются по команде.
- **Стиль не выбран.** На этапе 7 делаем 2–3 тестовых варианта (ближе к реализму и полуреалистичный) и выбираем по ощущениям на телефоне.

## Ограничения

- Реалистичную модель нужно облегчить для S25: меньше полигонов, текстуры 2K.
- Риск «зловещей долины» для ультрареалистичного лица — проверяем в тестах.
