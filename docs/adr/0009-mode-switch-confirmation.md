# ADR 0009: Переключение режима с переспросом

Дата: 2026-10-17 · Статус: принято

## Решение

- Фразы вроде «моё рабочее время закончилось», «у меня обеденный перерыв», «всё, я могу идти домой» не переключают режим сразу. Мира мягко и нейтрально переспрашивает («Перерыв? Мне переключиться?») и переключается только после явного «да».
- Если ответ «нет»/«оговорился» или вместо ответа идёт обычный вопрос — режим не меняется.
- Команда срабатывает только на короткой фразе (до 8 слов), не внутри обычного предложения.
- Возврат к работе («паника», «за работу») — мгновенно, без вопросов.
- На телефоне к подтверждению добавится отпечаток пальца для приватного режима.

## Почему

Оговорка при коллегах не должна включать приватный режим. Вопрос сформулирован так, чтобы посторонний не понял, о чём речь.
