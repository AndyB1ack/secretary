# ADR 0007: Одна модель без цензуры на все режимы

Дата: 2026-10-17 · Статус: принято; конкретная модель выбирается на этапе 2

## Решение

Вместо двух языковых моделей (рабочей и приватной) — одна модель без цензуры. Режимы отличаются только системным промптом, сценой и гардеробом.

## Почему

- Экономия памяти и места на телефоне.
- Смена режима мгновенная: модель не перезагружается.
- Одна модель — один набор тестов и одна настройка.

## Выбор модели

Сравниваем на Mac по эталонным диалогам: русский язык, рабочие ответы по документам, команды в JSON, живость персонажа, приватные диалоги без отказов.

- Кандидаты: abliterated-версии Qwen3 4B, Qwen3 8B и Gemma 3 4B в формате GGUF.
- 4B — точно помещается на S25 вместе с 3D. 8B (около 5 ГБ) заметно умнее, но вдвое медленнее и впритык по памяти — проверяем на телефоне на этапе 6.

## Риски

- Снятие цензуры иногда немного снижает качество и делает модель более «соглашающейся». В рабочем режиме ответы по-прежнему опираются на документы со ссылками; эталонные диалоги ловят деградацию.
- Фильтр приватных записей для облачного шлюза (ADR 0003) остаётся в силе.
