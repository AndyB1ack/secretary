# ADR 0002: Сначала прототип на Mac

Дата: 2026-10-17 · Статус: принято

## Решение

Голос, персонаж, память и база знаний сначала собираются на Python на Mac. На Android переносится уже отлаженная логика.

## Почему

На компьютере итерации в разы быстрее: не нужно собирать APK, проще менять модели и промпты.

## Следствия

Логику прототипа нужно писать так, чтобы её легко было повторить на Kotlin: те же модули, те же события, те же форматы данных.
