# ADR 0004: Пакеты знаний по моделям лифтов, картинки и облачный архив

Дата: 2026-10-17 · Статус: принято

## Решение

1. **Пакет на модель лифта.** База знаний собирается отдельными пакетами: один пакет — одна модель или серия (например, KONE MonoSpace). На телефоне лежат только пакеты моделей, которые стоят на текущих объектах.
2. **Картинки — полноценная часть базы.** Чертежи, схемы и иллюстрации сохраняются как изображения (сжатые в WebP), а не только как текст.
3. **Описание картинок делает Claude при сборке**, на компьютере, один раз:
   - контекст из документа: подпись, раздел, текст вокруг;
   - анализ самой картинки: что изображено, детали, размеры, клеммы;
   - ключевые слова на русском, английском и иврите.
   Описание индексируется вместе с текстом. Локальная модель ищет по описанию, а пользователю показывает саму картинку на экране и озвучивает: «смотри рисунок 12, страница 37».
4. **Полный архив в облаке.** Все пакеты хранятся на Google Диске пользователя (бесплатная квота). Телефон скачивает пакет при появлении нового объекта или по запросу, когда есть сеть. GitHub для пакетов не используется: он плохо подходит для больших бинарных файлов.
5. **Языки.** Документы на русском, английском, иврите, изредка на китайском. Ивритские и китайские тексты разово переводятся на русский при сборке; в пакете хранятся оригинал и перевод, ссылки ведут на страницу оригинала.

## Почему

На монтаже картинка часто важнее текста. Маленькая локальная модель картинки не понимает, поэтому понимание переносится на этап сборки, а на телефоне остаётся быстрый поиск по готовым описаниям. Все мануалы на телефоне не поместятся и не нужны.

## Следствия

- Формат пакета: SQLite-файл (текст, описания, эмбеддинги, метаданные) плюс папка изображений, упакованные в один архив `.kpack`.
- В пакете хранится версия документа и дата, чтобы отличать старые инструкции от новых (линейка KONE обновляется).
- Описание картинок через Claude стоит денег разово, при сборке пакета; на телефоне всё бесплатно.
