# 0012. Голос с эмоциями — Qwen3-TTS (целевой), Silero baya — запасной

Дата: 2026-10-17. Статус: принято (Мак), исследуется (телефон).

## Контекст
Андрей прослушал Piper Irina, Silero (xenia/baya/kseniya), Qwen3-TTS. Лучше всех — Qwen3-TTS CustomVoice
(голос Serena + инструкция тона): живой, с эмоциями. VoiceDesign 1.7B — интересный, но «анимешный».
Silero v5_6 baya — хороший запасной (вопросы, восклицания), но без управления эмоциями.

## Решение
- Мира ставит в ответе метки тона `[радостно]`, `[обиженно]`, `[шёпотом]`… (`secretary/emotion.py`), голос их исполняет.
  Голоса без эмоций метки игнорируют. Мак: `python main.py --voice qwen`.
- Телефон, по шагам:
  1. Замер `android/scripts/bench_qwen_tts.sh` (qwentts.cpp, C++/GGML, 0.6B Q4/Q8). RTF < 1 → встраиваем как есть.
  2. Иначе — «кэш» голоса: на Маке Qwen озвучивает часы речи с разными эмоциями → дообучаем свой маленький Piper-голос
     (эмоция = отдельный диктор) → на телефоне быстрый голос «как Serena» с эмоциями.
  3. Плюс кэш частых фраз (приветствия, реакции, «Ха!») заранее озвученных Qwen.
- Лицензии: Qwen3-TTS — Apache 2.0, qwentts.cpp — MIT, Silero — CC BY-NC (только личное некоммерческое использование).

## Последствия
- На Маке голос медленнее Silero; если тормозит — `--voice silero`.
- Технологию держим в уме и для других проектов (игры, озвучка).

## Замеры на S25 Ultra (2026-10-17)
- CPU, qwentts.cpp, 0.6B Q4_K_M: RTF ≈ 1.8–1.9. Мозг голоса (Talker+Predictor) успевает (≈0.5 RTF на 4 потоках),
  тормозит кодек (CodecDecode ≈ 7–10 с на 7 с речи).
- Видеокарта, OpenCL: падает — нет get_rows для квантованных таблиц и операций кодека.
- Видеокарта, Vulkan (Adreno 830): Q4_K не компилируется драйвером; Q8_0 работает, но RTF ≈ 5 и не находит конец фразы.
- Вывод: живой Qwen на телефоне пока не тянем → путь 2 («кэш голоса»): `tools/voice_dataset.py` + обучение Piper.
