# Контекст для Claude

Проект Андрея: локальная голосовая ассистентка («секретарша») для Galaxy S25. Общаться с ним на русском.

- Архитектура: `docs/ARCHITECTURE.md`. Важные решения: `docs/adr/`.
- Принципы: offline-first, без подписок, каждый движок за интерфейсом, персонаж — данные в YAML, приватное не покидает телефон.
- Порядок работы: прототип на Python для Mac (этапы 2–5), затем Android (Kotlin + llama.cpp/whisper.cpp), затем Unity-аватар.
- Модели не коммитить — только ссылки в `models.yaml`.
- Новое важное решение — новый файл в `docs/adr/`.
