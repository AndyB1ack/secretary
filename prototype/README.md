# Прототип Миры для Mac

Этап 2: голосовой диалог полностью на Mac, без интернета (после скачивания моделей).

Цепочка: микрофон → Silero VAD → whisper.cpp → Qwen3 4B (llama.cpp, Metal) → нарезка на предложения → Silero TTS → динамик.

## Установка (один раз)

Нужен Python 3.11 или 3.12.

```bash
cd secretary/prototype
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/download_models.py      # ~3 ГБ: языковая модель и Whisper
```

Голос Silero и детектор речи скачаются сами при первом запуске (нужна сеть один раз).

## Запуск

```bash
python main.py --text                  # переписка в терминале — сначала проверить так
python main.py --text --speak          # переписка, она отвечает голосом
python main.py                         # полностью голосом
python main.py --mode evening          # стартовый режим: work, evening, private, weekend
python main.py --text --tutor en       # слой репетитора английского
```

## Память и настроение

Мира помнит прошлые разговоры, факты и задачи (`data/mira.db`, только на этом Mac). При выходе (`/quit` или Ctrl+C) она сжимает разговор в сводку, факты и задачи. Настроение меняется раз в день: с инерцией, а если долго не заходил — немного обижена.

Команды в переписке: `/tasks` — задачи, `/task текст` — добавить, `/done N` — выполнено, `/remember факт`, `/forget слово`, `/memory` — что она помнит, `/mood` — настроение.

Голосовые команды: «еду домой» → вечер, «обед, я один» → приват, «паника» или «за работу» → работа.

Перебивание по умолчанию выключено: без наушников Мира слышит саму себя. В наушниках можно включить `audio.barge_in: true` в `config.yaml`.

## Что смотрим на этом этапе

- **Задержка:** программа печатает время распознавания и через сколько после твоей фразы прозвучало первое слово. Цель — 1–2 секунды.
- **Русский язык модели:** живо ли звучит Мира, не путается ли.
- **Голос:** перебрать `tts.speaker` в `config.yaml` (xenia, baya, kseniya).
