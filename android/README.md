# Android-приложение Миры (скелет)

Основа — официальный пример `llama.android` из llama.cpp (MIT, см. `LICENSE-llama.cpp`), модуль `lib` — движок модели с кешем системного промпта.

Сейчас умеет: Gemma офлайн на телефоне, характер Миры из `persona/mira.yaml`, голосовой ввод (распознавание Android) и голосовой ответ (синтез Android) по предложениям.

Дальше: память и задачи (SQLite), база знаний, практика иврита, режимы, свой голос (sherpa-onnx), аватар.

## Сборка и установка

    bash android/scripts/build_and_install.sh

Скрипт сам: соберёт APK, поставит на телефон, перенесёт модель в папку приложения и запустит Миру.
