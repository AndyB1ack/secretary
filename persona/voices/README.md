# Голоса Миры

`mira_ref.wav` — образец голоса для F5-TTS (10–20 секунд, тихое помещение), `mira_ref.txt` — дословно, что в нём сказано.

Записать образец: `python scripts/voice_compare.py --record` (прочитать текст с экрана).

Голос — только с согласия того, кто его записал. Записи в git не попадают.
